# Coherent Control of Wave Scattering via Minimal Parameter Tuning of Complex Spectra
This repository contains companion tutorial codes to the preprint [^1]. A part of these codes rely on [ChunkIE](https://github.com/fastalgorithms/chunkie) [^2], a freely available fast integral equation solver, which is described in detail [here](https://chunkie.readthedocs.io/en/latest/guide.html). The other codes rely on the commercial software COMSOL and running them requires an active COMSOL license with an RF-module. [^2]: Fast Algorithms Group. (2025). *ChunkIE: A MATLAB integral equation toolbox* (Version 1.0.0). [Source Code](https://github.com/fastalgorithms/chunkie).
